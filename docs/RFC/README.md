# RFCs

The numbered RFCs of this repository live here. The procedure that produces them ships with the
template: see [`.code-server/docs/agent/en/RFC.md`](../../.code-server/docs/agent/en/RFC.md), and
[the RFC form](../../.code-server/docs/agent/en/RFC-TEMPLATE.md) for the form to copy.

This folder is empty, which is the correct state here: this is the template, not a project built
on it, and the numbered files start in the repositories that adopt it.
